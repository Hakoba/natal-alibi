# Натальное алиби

**Потыкать можно тут: https://useopora.com/natal/**

Шуточная страница. Вы вводите дату и город рождения, а она подбирает, какое **время**
рождения называть, чтобы асцендент вышел нужный: для девушки, для парня и его мамы, для HR
или просто на свой вкус. Заодно показывает худшее время, которое называть не надо.
Дата остаётся настоящей. За сутки асцендент проходит все 12 знаков, так что нужный
подбирается одним временем.

> **Дисклеймер.** Астрология не наука. Страница показывает, что в выдуманной системе
> правильный ответ можно выдумать по её же правилам.

Астрономия тут настоящая. Положения Солнца и Луны берутся из эфемерид, асцендент считается
по формуле через звёздное время, широту и наклон эклиптики. Часовые пояса исторические,
декретное время СССР учитывает `Intl.DateTimeFormat`. Толкования знаков мы придумали сами.

- `index.html` — вся страница (инлайн CSS/JS): дизайн «небесная канцелярия», мем-созвездия и пасхалки.
- `natal.js` — ядро: асцендент/MC (формулы), знаки, перебор суток, скоринг окон. UMD: браузер + node.
- `astronomy.browser.min.js` — вендоренный [astronomy-engine](https://github.com/cosinekitty/astronomy) (MIT): Солнце, Луна, сидерическое время.
- `sky-map.jpg` — Planisphæri cœleste, F. de Wit, 1670 (Wikimedia Commons, public domain), водяной знак справки.
- `test.mjs` — самопроверка, `npm test`: GAST по Меёсу, асцендент против восхода Солнца, MC против полудня, непрерывность окон, исторические таймзоны.

## Глоссарий

- **Асцендент** — знак зодиака, который восходил над восточным горизонтом в минуту рождения. Меняется примерно каждые два часа, поэтому его и можно подобрать временем.
- **MC** (Medium Coeli, «середина неба») — точка, где эклиптика пересекает небесный меридиан. В астрологии отвечает за карьеру, поэтому на неё смотрит HR-пресет.
- **Эклиптика** — круг, по которому Солнце за год идёт по небу (строго говоря, это плоскость земной орбиты). Знаки зодиака — её 12 секторов по 30°.
- **Наклон эклиптики** — угол ~23,4° между эклиптикой и небесным экватором. Это тот же наклон земной оси, из-за которого меняются времена года. Он входит в формулу асцендента.
- **Эфемериды** — расчётные положения небесных тел на заданный момент. Здесь их выдаёт astronomy-engine.
- **Звёздное (сидерическое) время** — время по повороту Земли относительно звёзд. Звёздные сутки короче солнечных примерно на 4 минуты. По нему понятно, какой кусок неба сейчас над горизонтом.
- **GAST** (Greenwich Apparent Sidereal Time) — истинное звёздное время на гринвичском меридиане. Если прибавить долготу города, получится местное звёздное время для формулы.
- **Меёс** — Жан Меёс, автор «Astronomical Algorithms», настольной книги расчётной астрономии. Тест сверяет наш GAST с его формулами.
- **Декретное время** — советский сдвиг часов на час вперёд с 1930 года (плюс позднейшие скачки). Из-за него вопрос «который час был в Свердловске в 1975-м» не такой простой. Отвечает на него `Intl.DateTimeFormat`.

Локально: открыть `index.html` в браузере (file:// работает) или `python3 -m http.server`.
