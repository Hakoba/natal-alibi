# Натальное алиби

**Живая версия: https://useopora.com/natal/**

Шуточная страница: по дате и городу рождения подбирает, какое **время** рождения называть,
чтобы получить нужный асцендент (девушке / парню и его маме / HR / на свой вкус), плюс
«худшее время» по анти-пресету. Дата не искажается — время рождения за сутки прокручивает
асцендент через все 12 знаков, остаётся выбрать окно.

Расчёт честный: положения Солнца и Луны по эфемеридам, звёздное время, асцендент по формуле
через широту и наклон эклиптики, исторические часовые пояса (декретное время СССР учтено
через `Intl.DateTimeFormat`). Интерпретации — цирк, как и положено.

- `index.html` — вся страница (инлайн CSS/JS), дизайн «небесная канцелярия».
- `natal.js` — ядро: асцендент/MC (формулы), знаки, перебор суток, скоринг окон. UMD: браузер + node.
- `astronomy.browser.min.js` — вендоренный [astronomy-engine](https://github.com/cosinekitty/astronomy) (MIT) — Солнце/Луна/сидерическое время.
- `sky-map.jpg` — Planisphæri cœleste, F. de Wit, 1670 (Wikimedia Commons, public domain) — водяной знак справки.
- `test.mjs` — самопроверка: `node test.mjs` (GAST по Меёсу, асцендент против восхода Солнца, MC против полудня, непрерывность окон, исторические таймзоны).

Локально: открыть `index.html` в браузере (file:// работает) или `python3 -m http.server`.

Дисклеймер: астрология — не наука. Страница доказывает ровно один тезис: если система
выдумана целиком, то «правильный» ответ в ней можно выдумать по всем её же правилам.
