# Натальное алиби

**Живая версия: https://useopora.com/natal/**

Шуточная страница: по дате и городу рождения подбирает, какое **время** рождения называть,
чтобы получить нужный асцендент (девушке / парню и его маме / HR / на свой вкус), плюс
«худшее время» по анти-пресету. Дата не искажается: время рождения за сутки прокручивает
асцендент через все 12 знаков, остаётся выбрать окно.

> **Дисклеймер.** Астрология — не наука. Страница доказывает ровно один тезис: если система
> выдумана целиком, то «правильный» ответ в ней можно выдумать по всем её же правилам.

Расчёт честный: положения Солнца и Луны по эфемеридам, звёздное время, асцендент по формуле
через широту и наклон эклиптики, исторические часовые пояса (декретное время СССР учтено
через `Intl.DateTimeFormat`). Интерпретации — цирк, как и положено.

- `index.html` — вся страница (инлайн CSS/JS): дизайн «небесная канцелярия», мем-созвездия и пасхалки.
- `natal.js` — ядро: асцендент/MC (формулы), знаки, перебор суток, скоринг окон. UMD: браузер + node.
- `astronomy.browser.min.js` — вендоренный [astronomy-engine](https://github.com/cosinekitty/astronomy) (MIT): Солнце, Луна, сидерическое время.
- `sky-map.jpg` — Planisphæri cœleste, F. de Wit, 1670 (Wikimedia Commons, public domain), водяной знак справки.
- `test.mjs` — самопроверка, `npm test`: GAST по Меёсу, асцендент против восхода Солнца, MC против полудня, непрерывность окон, исторические таймзоны.

## Глоссарий

- **Асцендент** — знак зодиака, который восходил над восточным горизонтом в минуту рождения. Сменяется примерно каждые два часа — поэтому его и можно «подобрать» временем.
- **MC** (Medium Coeli, «середина неба») — точка, где эклиптика пересекает небесный меридиан; в астрологии отвечает за карьеру, чем и дорога HR-пресету.
- **Эклиптика** — круг, по которому Солнце за год идёт по небу (на самом деле это плоскость земной орбиты). Знаки зодиака — её 12 секторов по 30°.
- **Наклон эклиптики** — угол ~23,4° между эклиптикой и небесным экватором. Тот самый наклон земной оси, что даёт смену времён года; входит в формулу асцендента.
- **Эфемериды** — расчётные положения небесных тел на заданный момент. Здесь их выдаёт astronomy-engine.
- **Звёздное (сидерическое) время** — время по повороту Земли относительно звёзд, а не Солнца; звёздные сутки короче обычных на ~4 минуты. Нужно, чтобы понять, какой кусок неба сейчас над горизонтом.
- **GAST** (Greenwich Apparent Sidereal Time) — истинное звёздное время на гринвичском меридиане; прибавляем долготу города — получаем местное звёздное время для формулы.
- **Меёс** — Жан Меёс, автор «Astronomical Algorithms», настольной книги расчётной астрономии. Тест сверяет наш GAST с его формулами.
- **Декретное время** — советский сдвиг часов на час вперёд с 1930 года (плюс позднейшие скачки). Из-за него «который час был в Свердловске в 1975-м» — нетривиальный вопрос; отвечает на него `Intl.DateTimeFormat`.

Локально: открыть `index.html` в браузере (file:// работает) или `python3 -m http.server`.
